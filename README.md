=====CAMALEONS=====
CamaLeons é uma fornecedora de camas e itens de conforto em geral.
    Seus produtos principais incluem (mas não se limitam) a:
    1. Camas prontas, colchões, edredons, lençóis e travesseiros;
    2. Sofá-camas, almofadas, sofás e poltronas;
    3. Camas infláveis e sacos de dormir.

    Ma(ma)térias:
    1. Ma(ma)deira
    2. Espuma
    3. Algodão
